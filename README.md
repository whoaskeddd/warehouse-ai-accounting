# SmartStock AI

Локальное WPF-приложение для учета склада, движения товаров, инвентаризации, отчетности и AI-аналитики спроса без зависимости от интернета.

## Что умеет система

- каталог товаров, категорий, поставщиков и локаций;
- приходные и расходные документы;
- резервирование и журнал движений;
- инвентаризация и акты расхождений;
- пользователи, роли, аудит ключевых операций;
- backup/restore;
- отчеты и импорт/экспорт;
- AI-прогноз спроса;
- AI-автокатегоризация товаров;
- AI-рекомендации по закупке и дефициту.

## Стек

## Как работает AI

### 1. Прогноз спроса

Для первой версии используется `ML.NET SSA`.

Источник данных:

- только движения типа `Issue`

Что делает система:

1. собирает историю расхода;
2. агрегирует расход по месяцам;
3. пересчитывает прогноз на `6`, `9`, `12` месяцев;
4. сохраняет результат в кэш и метаданные модели.

Если у товара меньше `3` месяцев истории:

- используется fallback по родительской или текущей категории.

### 2. Автокатегоризация

Для автокатегоризации используется `ML.NET multiclass text classification`.

Обучающие данные:

- существующие товары из базы, у которых категория была задана вручную.

Вход:

- `Name` товара.

Выход:

- одна рекомендуемая категория;
- confidence модели;
- признак сильной рекомендации.

Порог сильной рекомендации:

- `0.75`

Если confidence ниже порога:

- UI показывает подсказку, но не назначает категорию автоматически.

### 3. Рекомендации по закупке

Формула первой версии:

```text
ForecastLeadTime = MonthlyForecast * LeadTimeMonths
SafetyStock = MonthlyForecast * SafetyStockMonths
RecommendedOrder = (ForecastLeadTime + SafetyStock) - CurrentStock - ExpectedInbound
```

Где:

- `LeadTimeMonths` — глобальный срок поставки;
- `SafetyStockMonths` — страховой запас в месяцах спроса;
- `ExpectedInbound` — ожидаемый приход из черновиков приходных документов.

## Как обучить модель на своих данных

1. Создать категории.
2. Завести товары и вручную назначить им категории.
3. Добавить историю расходных документов.
4. Провести документы.
5. Нажать `Пересчитать AI`.

Минимум для нормального результата:

- для прогноза товара: от `3` месяцев расхода;
- для лучшего результата: `6+` месяцев;
- для автокатегоризации: несколько товаров в каждой категории с нормальными названиями.

- `manager` / `Manager123!`

- `admin` / `Admin123!`

По умолчанию вход администратором в UI закрыт. Для временного включения:

```powershell
$env:SMARTSTOCKAI_ENABLE_ADMIN_LOGIN="1"
dotnet run --project .\src\SmartStockAI.App\SmartStockAI.App.csproj
```
