# Техническое задание: SmartStock AI

**Тип приложения:** Desktop-приложение (Windows), полностью автономное, без интернета  

## 1. Общее описание проекта

SmartStock AI — локальная система управления складом с встроенным ИИ для прогнозирования спроса. Основная цель — автоматизация учета товаров, оптимизация закупок и предотвращение дефицита запасов через точное прогнозирование на 6, 9 и 12 месяцев вперед.

**Ключевые бизнес-задачи:**
- Хранение полной истории товаров (24+ месяца)
- Прогнозирование спроса с доверительными интервалами (10-90%)
- Автоматические рекомендации по закупкам
- Оптимизация логистики сборки заказов
- Инвентаризация и аудит

## 4. Архитектура ИИ-модели

### 4.1. Входные данные
- История продаж/расходов (24+ мес)
- Приходы
- Календарные признаки (день недели, праздники)
- Категории, параметры товаров

### 4.2. Этапы обработки
```
Входные данные → Предобработка → [SARIMA || LSTM] → Ансамблирование → Постобработка → Прогноз
```

**Предобработка:**
1. Фильтрация выбросов (корректировки)
2. Заполнение пропусков (=0)
3. Детрендирование

**SARIMA:**
- S (сезонность), AR (авторегрессия), I (интеграция), MA (скользящее среднее)
- Автоподбор через grid search

**LSTM (опционально):**
```
60 дней → LSTM(128) → Dropout(20%) → LSTM(64) → Dense(32) → Прогноз
```
Требует 12-18 мес данных

**Ансамблирование:**
```
Прогноз = w_sarima × SARIMA + w_lstm × LSTM
```
Веса по backtesting (MAPE) за 3 мес

### 4.3. Метрики качества
- **MAPE** (Mean Absolute Percentage Error): <10% — отлично, 10-20% — хорошо
- **RMSE** (Root Mean Square Error)
