## Shared Contracts

Этот документ фиксирует минимальные общие сущности и поля для шагов 1-2. Его задача: дать стабильную основу для UI и backend, пока модель еще не расширена полным функционалом ТЗ.

### Что стабильно на шаге 1

- названия сущностей;
- основные первичные ключи;
- основные связи товара со справочниками;
- базовые поля для карточки товара и журнала движений.

### Что может быть расширено на шаге 2

- дополнительные поля карточки товара;
- изображения;
- атрибуты категорий;
- дополнительные поля пользователей;
- расширенные поля документов;
- аудит и служебные поля.

### Product

Обязательные поля:

- `Id`
- `Sku`
- `Name`
- `CategoryId`
- `SupplierId`
- `LocationId`
- `Unit`
- `CurrentStock`
- `MinStock`
- `PurchasePrice`
- `SalePrice`

Уже можно использовать в UI:

- список товаров;
- карточка товара;
- поиск и фильтры;
- отображение остатков.

Может быть расширено позже:

- изображения;
- пользовательские атрибуты;
- статус товара;
- audit-поля.

### Category

Обязательные поля:

- `Id`
- `Name`
- `ParentCategoryId`

Уже можно использовать в UI:

- список категорий;
- выбор категории в карточке товара.

Может быть расширено позже:

- описание;
- атрибуты категории;
- сортировка и метаданные дерева.

### Supplier

Обязательные поля:

- `Id`
- `Name`
- `ContactInfo`

Уже можно использовать в UI:

- список поставщиков;
- выбор поставщика в карточке товара.

Может быть расширено позже:

- срок поставки;
- реквизиты;
- тип поставщика.

### Location

Обязательные поля:

- `Id`
- `Name`
- `ParentLocationId`

Уже можно использовать в UI:

- список локаций;
- выбор локации в карточке товара.

Может быть расширено позже:

- код ячейки;
- тип локации;
- вместимость.

### User

Обязательные поля:

- `Id`
- `Login`
- `DisplayName`
- `Role`

Уже можно использовать в UI:

- базовый экран пользователей;
- отображение текущего пользователя.

Может быть расширено позже:

- пароль;
- статус активности;
- права доступа.

### StockMovement

Обязательные поля:

- `Id`
- `ProductId`
- `Type`
- `Quantity`
- `CreatedAt`
- `DocumentNumber`

Уже можно использовать в UI:

- история движений товара;
- список операций по товару.

Может быть расширено позже:

- комментарий;
- пользователь операции;
- тип документа;
- связанный документ.
